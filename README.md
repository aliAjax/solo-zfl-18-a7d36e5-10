# 桌游规则遗忘点卡片库 + 版本兼容验算台

一个纯前端本地应用，包含两个标签页：

## 收藏卡片（原有功能）

管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 版本兼容验算台

- **版本登记**：为每款桌游登记基础版本与扩展，记录组件依赖、互斥关系、人数/时长修正和效果标签。
- **组合验算**：选择基础版本、扩展和人数后实时判定可玩性；缺少依赖、循环依赖、重复扩展、互斥/效果冲突、人数超范围都会被拦住，无法发布。
- **组合生命周期**：草稿 → 发布 → 归档，支持恢复、撤销（回到任一历史内容）和更换基础版本；每次改动保留旧修订，历史局次自动标记"受影响"。
- **导入导出**：导出 JSON 备份；导入前校验失效引用、版本冲突、缺组件和重复组合，任一错误都整体拒绝，原数据不被覆盖。
- **多页协同**：多个浏览器页面同时编辑时按实体修订号自动合并；同实体并发修改会弹出冲突横幅，由人工选择保留哪边，绝不静默覆盖。
- **刷新恢复**：搜索筛选、当前标签页和未保存的组合草稿在刷新后自动恢复。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问：

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123
```
